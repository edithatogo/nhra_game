# Assumptions log

This log is a living record of assumptions that are **not** directly parameterised from a public source.

**Rule:** if a parameter is not empirically sourced, it must have:

- a clear rationale (why this assumption is reasonable for a stylised mechanism model), and
- a stated plausible range used in sensitivity analysis.

The single source of truth for parameter-level documentation is `context/04_parameter_registry.csv`.

## Current high-impact assumptions (track for refinement)

- Rurality and remoteness mix fractions used to compute an “efficiency gap”.
- Mappings from pressure → ED≤4h and offload minutes (calibration/normalisation).
- Behavioural/payoff weights in stage games (political salience, bargaining cost, audit pressure).
