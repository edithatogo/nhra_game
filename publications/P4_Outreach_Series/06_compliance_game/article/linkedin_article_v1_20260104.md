# The "Compliance Game": the cat-and-mouse world of hospital funding

If you pay hospitals for activity, someone has to check if the activity actually happened.

This creates the **Compliance Game** between **Administrators** (who audit) and **Providers** (who code).

## The real-world situation

Under Activity-Based Funding (ABF), a hospital gets paid more for a complex patient than a simple one.
So there is a strong incentive to "upcode"—to find every possible diagnosis to maximize revenue.

The Administrator (e.g., IHACPA/State) wants to stop fraud but can't audit every single record. It's too expensive.

## The "game" incentives

We model this as an Inspection Game (like tax auditing or ticket inspectors).

- **Tight Audit**: Admin checks frequently. High cost, but catches gaming.
- **Light Audit**: Admin saves money on auditors.
- **Comply**: Provider reports accurately.
- **Game (Upcode)**: Provider inflates the claim.

## The Equilibrium: "Mixed Strategy" (Randomness)

There is no stable single strategy here.
- If the Admin never audits, the Provider will always Game.
- If the Provider always Games, the Admin will always Audit.
- If the Admin always Audits, the Provider will Comply.
- If the Provider Complies, the Admin will stop Auditing (to save money).

So the equilibrium is a cycle (or a random mix). The Admin audits *just enough* to make Gaming risky. The Provider games *just enough* to push the boundary.

## Why this matters

This "cat and mouse" game consumes huge resources.
Hospitals hire "Clinical Coders" to maximize revenue.
Governments hire "Auditors" to claw it back.

None of this improves patient care. It is pure transaction cost.

## How to fix it

- **Simplification**: Reduce the number of price codes so there are fewer "border disputes."
- **Bundled payments**: Pay for a "Year of Care" rather than per-episode (harder to game).
- **Automated auditing**: Use AI to detect anomalies at scale, lowering the cost of inspection.

## TL;DR

- Paying for activity creates an incentive to "upcode."
- Auditing creates a "Compliance Game" (Cat and Mouse).
- The solution is simpler pricing or automated transparency, not just "more inspectors."
