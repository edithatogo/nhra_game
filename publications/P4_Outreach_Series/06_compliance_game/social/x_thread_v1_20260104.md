1/ Why do governments hire auditors to check hospital paperwork? 🕵️‍♂️🏥

It’s the **Compliance Game**. And it costs the system millions. 🧵

2/ The Setup:
Hospitals get paid via Activity-Based Funding (ABF).
Complexity = $$$$.

So hospitals hire coders to find every diagnosis. "Upcoding." 📈

3/ The Counter-Move:
The Funder hires Auditors to find errors and claw back money. 📉

It’s a classic **Inspection Game** (like ticket inspectors on a train).

4/ The Game Theory:
There is NO stable "pure" strategy.

If Auditors sleep -> Hospitals game.
If Hospitals game -> Auditors wake up.
If Auditors wake up -> Hospitals comply.
If Hospitals comply -> Auditors sleep (to save money). 🔁

5/ It’s a "Mixed Strategy Equilibrium."
Random audits. Random gaming.
Perpetual cat-and-mouse. 😼🐭

6/ The Cost:
Huge "transaction costs."
Salaries for coders. Salaries for auditors.
None of this treats a patient. It's just fighting over the bill. 💸

7/ The Fix?
You can't "win" the game, you have to change it.

✅ **Bundled Payments**: Pay for outcomes, not codes.
✅ **Simplicity**: Fewer price tiers = fewer arguments.
✅ **Tech**: Automated anomaly detection (low cost audit).
