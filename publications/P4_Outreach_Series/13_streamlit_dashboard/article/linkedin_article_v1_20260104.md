# How to use the NHRA Dashboard (without needing a PhD)

Policy is complex. But exploring it shouldn't be.

We built an interactive **Streamlit Dashboard** to let you play with the NHRA Game yourself.

## What you can do

### 1. Change the Scenarios
What happens if we increase the **Cost Shifting** incentive?
What happens if we reduce **GP Access**?
What happens if we force **Pooled Funding**?

### 2. See the Feedback Loops
Watch how a change in "Primary Care" flows through to "ED Wait Times" and eventually "State Budget Deficits."
It's not linear. It's a web of reactions.

### 3. Compare Policy Options
We pre-loaded common policy proposals (e.g., "The 2025 Reform Package").
You can see which ones actually fix the problem, and which ones just move it.

## How to read the charts

- **Trajectories**: The lines show the system state over 10 years.
- **Phase Plots**: The spirals show how two variables (e.g., Quality vs Cost) trade off against each other.
- **Sensitivity**: The tornado charts show which levers matter most.

## Why we built it

Models in PDFs die. Models on the web live.
We want policymakers, journalists, and the public to be able to "test drive" the health system.
