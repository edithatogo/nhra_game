Tweet 1: NHRA negotiations can look odd from the outside: “Why don’t they just agree?” Game theory answer: waiting can be rational if it changes leverage.

Tweet 2: Players (simplified): Commonwealth + States/Territories. Choice at a moment in time: agree now (certainty) or hold out (maybe better terms).

Tweet 3: If one side agrees while the other holds out, the hold-out side can improve its deal. That creates an incentive to “play tough”.

Tweet 4: If BOTH hold out, the outcome can be delay + uncertainty. Equilibrium isn’t “best” — it’s what sticks when neither side can improve by changing alone.

Tweet 5: The kicker: time isn’t free. Waiting can shrink the total value (discounting + system pressure). Draft article + diagrams: ../article/linkedin_article_v1_20260104.md
