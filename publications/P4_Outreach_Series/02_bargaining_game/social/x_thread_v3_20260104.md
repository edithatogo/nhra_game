Tweet 1: Why do big health funding negotiations sometimes… wait? Game theory answer: waiting can be rational if it changes leverage.

Tweet 2: Players (simplified): Commonwealth + States/Territories. Each can agree now (certainty) or hold out (maybe better terms).

Tweet 3: Tiny example: “Sign now with clear rules” vs “Wait for more flexibility”. Neither is automatically bad — but it sets up incentives to wait for the other side to blink.

Tweet 4: If one side agrees while the other holds out, the hold-out can gain leverage. If both hold out, delay/uncertainty becomes the outcome. Depending on payoffs, equilibria can differ — the point is the incentive to wait.

Tweet 5: Time isn’t free. Waiting can shrink the total value (“discounting”): like arguing about pizza toppings until it’s cold. Policy question: if no agreement by date X, what happens by default? Draft: ../article/linkedin_article_v3_20260104.md
