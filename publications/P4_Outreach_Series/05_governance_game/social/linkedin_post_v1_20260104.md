# Control vs Autonomy: The eternal health struggle 🏛️🏥

Who runs the hospital? The local CEO or the Ministry in the city?

This is the **Governance Game**.

In our latest Game Theory model, we look at the incentives between **State Ministries (MOH)** and **Local Hospital Networks (LHNs)**.

MOH wants **Standardisation** (Control).
LHN wants **Agility** (Autonomy).

If you control too tightly, local teams disengage. "Just following orders." 🤖
If you let go too much, the system fragments. "Cowboy country." 🤠

The equilibrium? A messy "Separate" where both sides pull in opposite directions.

The fix isn't more rules—it's **Earned Autonomy**.
Use real-time data to build trust. If the outcome is good, let the local team drive.
